## Wie we zijn

Ondernemers verliezen elke week uren aan werk dat niets oplevert: overtypen, opzoeken, nabellen, bijhouden.
EasyBY zoekt uit waar die uren blijven, zet het op een rij en bouwt er een passende automatisering voor.

Zodat jij weer doet wat je het liefste doet: **ondernemen**.

## Hoe we werken

|     | Stap              | Wat we doen                                      |
| :-: | ----------------- | ------------------------------------------------ |
| 01  | **Ontdekken**     | Meekijken in je dag. Waar gaat de tijd heen?     |
| 02  | **In kaart**      | Elk tijdlek benoemd, met wat het je kost.        |
